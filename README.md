# قشنگ‌ترین گل دنیا — سورپرایز تعاملی روز دختر

یک سایت استاتیک کاملاً فارسی و موبایل‌پسند با ۹ سکانس، ساخته‌شده از تصویر مرجع شما.
بدون سرور، بدون پایگاه داده و بدون API؛ فونت‌ها و تصاویر همگی داخل پروژه هستند.

## مسیر تجربه (۹ سکانس)
1. معرفی: «یه سوال مهم؟» و سؤال «به نظرت قشنگ‌ترین گل کدومه؟»
2. انتخاب یکی از شش گل (رز، لیلیوم، نیلوفر آبی، لاله، آفتابگردان، شکوفه گیلاس)
3. تا ۸. پاسخ اختصاصی همان گل: «[گل] هم …» و بعد «...اما» (به‌طور خودکار ادامه می‌یابد؛ با لمس هم می‌شود زودتر رفت)
9. (با قلب کوچک و دکمه‌ی «شروع دوباره» در پایان) «جوابت غلطه!» ← «[گل انتخاب‌شده] هم قشنگه‌ها...» ← «ولی قشنگ‌ترین گل دنیا تویی» ← «قشنگ‌ترین گل دنیا، روزت مبارک!»

## اجرا روی کامپیوتر
فایل `index.html` را مستقیم در مرورگر باز کنید. یا برای تست شبیه سرور واقعی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

## انتشار رایگان و گرفتن لینک عمومی
**GitHub Pages**
1. در GitHub یک مخزن Public بسازید (مثلاً `ghashang-tarin-gol`).
2. همه‌ی فایل‌های این پوشه را آپلود کنید (`index.html` باید در ریشه‌ی مخزن باشد).
3. Settings ← Pages ← Source: `Deploy from a branch` ← شاخه‌ی `main` و پوشه‌ی `/(root)` ← Save.
4. بعد از ۱ تا ۲ دقیقه لینک شما `https://USERNAME.github.io/ghashang-tarin-gol/` می‌شود.

**Netlify Drop (ساده‌ترین)**: به app.netlify.com/drop بروید و کل پوشه را بکشید و رها کنید؛ لینک عمومی همان لحظه ساخته می‌شود.

**Cloudflare Pages**: یک پروژه‌ی جدید از نوع Direct Upload بسازید و پوشه را آپلود کنید.

## ساختار فایل‌ها
```
index.html          صفحه‌ی اصلی و دو سکانس اول
css/style.css       ظاهر، انیمیشن‌ها و سازگاری با کاهش حرکت
js/script.js        منطق تعاملی و سکانس‌های ۳ تا ۹
images/bg-*.jpg     پس‌زمینه‌ها (از قاب‌های تصویر مرجع، بدون متن)
images/<flower>.jpg عکس شش گل برای کارت‌های انتخاب
fonts/              Vazirmatn و Lalezar (مجوز OFL)
```

## ویرایش متن‌ها
- متن‌های سکانس‌های ۱ و ۲: `index.html`
- متن هر گل و پیام نهایی: آرایه‌ی `FLOWERS` و بخش «سکانس ۹» در `js/script.js`

## نکته‌ها
- تصاویر از قاب‌های تصویر مرجع برش خورده‌اند؛ برای تیزتر شدن روی نمایشگرهای بزرگ، می‌توانید نسخه‌ی اصلی و با کیفیت‌ترشان را جایگزین کنید (با همان نام فایل).
- انیمیشن‌ها فقط با `transform` و `opacity` ساخته شده‌اند و اگر گوشی روی «کاهش حرکت» باشد، ساده‌تر می‌شوند.
