# سورپرایز تعاملی روز دختر

یک وب‌سایت استاتیک فارسی با HTML، CSS و JavaScript؛ بدون نیاز به نصب، پایگاه داده یا API.

## اجرا
1. فایل ZIP را کامل استخراج کنید.
2. پوشه `ghashang-tarin-gol` را باز کنید.
3. فایل `index.html` را با Chrome، Edge، Firefox یا Safari باز کنید.
4. اگر تصاویر نمایش داده نمی‌شوند، مطمئن شوید پوشه‌های `css`، `js` و `images` کنار `index.html` هستند و فقط خود فایل HTML را جدا نکرده‌اید.

## ساختار
- `index.html`: سکانس‌ها و متن‌ها
- `css/style.css`: ظاهر، چیدمان واکنش‌گرا و انیمیشن‌ها
- `js/script.js`: انتخاب گل و جابه‌جایی بین مراحل
- `images/`: تصاویر گل‌ها و برش‌های پنل‌های تصویر مرجع

## انتشار رایگان با GitHub Pages
1. یک repository جدید در GitHub بسازید.
2. تمام محتویات پوشه `ghashang-tarin-gol` (نه فقط فایل ZIP) را بارگذاری کنید.
3. در `Settings → Pages`، بخش انتشار از شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
4. پس از چند دقیقه، نشانی عمومی‌ای که GitHub Pages نمایش می‌دهد قابل استفاده است.

## نکته درباره تصاویر
برش‌های پنل از تصویر مرجع پیوست‌شده استخراج شده‌اند تا سبک و عکس‌ها تا حد ممکن نزدیک به مرجع بمانند. کیفیت آن‌ها به وضوح تصویر مرجع محدود است.
